3. How to Use the EVA Botanical Lexicon & Dictionary

3.1 Understanding EVA (European Voynich Alphabet)

The manuscript text is transcribed using EVA (European Voynich Alphabet), a standardized ASCII representation of Voynich glyphs.

EVA Token Botanical / Grammatical Meaning Medieval Latin Equivalent Clinical / Practical Translation
daiin "take / recipe minim" Recipe / Minim Primary prescription header ("Take 2 minims")
ol "the / sacred simplex" Herba / Simplex Simplex herb marker preceding plant name
chedy "mix / compound" Misce / Compone Compounding instruction for apothecary
otaiin "decoction / liquid extract" Decoctio / Liquor Aqueous or wine-steeped liquid extract
aiin "minim / fluid drop" Drop / Minim Unit of liquid dosage measurement
qokeey "purge / cleanse" Purga / Catharticum Evacuant or bowel purge directive
shedy "wash / lotion" Lotio / Lavacrum External wash or topical liniment
ykeey "boil / simmer" Coque / Ferveo Thermal extraction instruction

3.2 Step-by-Step Word Lookup Protocol

To look up any word token from the manuscript:

  1. Open the Lexicon Explorer: Navigate to the Lexicon Tab on https://voynich.ozark-oracle.com or open dist/lexicon.html.
  2. Search by EVA Token: Type the EVA string (e.g. daiin, chedy, ol) into the interactive search bar.
  3. Filter by Section: Select whether you are searching within Herbal titles, Jar labels, or Recipe paragraphs.
  4. Review Frequency & Cross-References: The system instantly displays:
  5. Total occurrences across the codex.
  6. Associated botanical folios where the token appears.
  7. Corresponding Salernitan pharmaceutical translation.

4. How to Use the Interactive Concordance Atlas & Labeled Page Map

4.1 Navigating the SVG Interactive Atlas

  1. Select a Folio: Click on any folio tab (e.g. f1r, f2v, f33v, f87r).
  2. Toggle Labeled Anatomical Zones: Click the "Show Anatomical Map" button. The high-resolution IIIF parchment image renders interactive color-coded diagnostic overlays:
  3. 🔵 Cyan Zones (Flowers / Corolla): Floral organ diagnostics.
  4. 🟢 Emerald Zones (Foliage / Lamina): Leaf margins, venation, and heterophylly.
  5. 🟠 Amber Zones (Rhizome / Rootstock): Primary diagnostic root anatomy (Radix).
  6. 🟣 Amethyst Zones (Albarelli / Vessels): Apothecary jar labels.

  7. 🟡 Gold Lines (Text Lines / Prescription Clauses): Transcribed EVA text lines.

  8. Hover & Inspect: Hover over any zone to view instant botanical diagnosis, photography comparisons from Köhler's Medizinal-Pflanzen, and Salernitan posology links.

5. How to Look Up Unidentified & Forgotten Plants

When encountering an unfamiliar or "surreal" plant drawing:

  1. Check the Root First: In classical botany, foliage changes with season, but root morphology is permanent. Examine whether the root is a single taproot (Hyoscyamus), a cluster of tubers (Sium sisarum - Skirret), a creeping scaly rhizome (Polygonatum), or an isolated subterranean sphere (Conopodium - Pignut).
  2. Check for Heterophylly: Compare lower basal leaves against upper stem leaves. If they differ, check the Heterophylly Matrix in VOYNICH_MORPHOLOGICAL_GROWTH_PATTERNS_MONOGRAPH.md.
  3. Consult the Master Botanical Index: Open VOYNICH_MASTER_BOTANICAL_INDEX_AND_PHARMACOPEIA.md or the Botanical Consensus Tab to view verified binomials, high-resolution photography, and Salernitan recipes.
